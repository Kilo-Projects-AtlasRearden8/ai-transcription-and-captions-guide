# Free AI Transcription and Captions Guide

A beginner-friendly manual on free AI transcription and captions for meetings, lectures, and videos. Covers local vs cloud options, editing transcripts, privacy rules, and export formats.

**Author:** Asdale Dynamics, LLC  
**Website:** [dylanasdale.github.io](https://dylanasdale.github.io)  
**Book:** [The Massive AI Manual](https://dylanasdale.github.io)

## Contents

- [Documentation](docs/) - Full written guide
- [Static Site](site/) - HTML version for web hosting

## Quick Start

### View the Documentation
Open `docs/index.md` or browse the markdown files in the `docs/` folder.

### View the Static Site
Open `site/index.html` in a web browser, or serve it locally:

```bash
# Python 3
python3 -m http.server 8000 -d site

# Node.js (npx)
npx serve site

# PHP
php -S localhost:8000 -t site
```

Then visit `http://localhost:8000`
