Chapter 14

Troubleshooting

Free AI Transcription and Captions Guide · Asdale Dynamics, LLC

Installation Problems

"pip: command not found"

Cause: Python isn't installed, or pip isn't in your system PATH.

Fix: Install Python from python.org. During installation on Windows, check "Add Python to PATH". Restart your terminal.

"ModuleNotFoundError: No module named 'faster_whisper'"

Fix: pip install faster-whisper

"ffmpeg: command not found"

Fix: Mac: brew install ffmpeg · Windows: ffmpeg.org/download.html · Linux: sudo apt install ffmpeg

Transcription Problems

Out of Memory / Computer Freezes

Fix: Use --model tiny. Close other applications. Restart your computer.

Transcription Is Very Slow

Fix: Use --model tiny or --model base. Close browser tabs. If you have an NVIDIA GPU, install CUDA support.

Model Download Fails

Fix: Check your internet connection. Try again — downloads resume automatically.

"File Not Found" Error

Fix: Use the full path: ~/Downloads/lecture.mp3. Or cd into the file's folder first.

Wrong Language Detected

Fix: Specify the language: --language en (English), --language es (Spanish).

Quality Problems

CauseFix
Background noiseRecord in a quieter place, closer to the speaker
Low volumeIncrease microphone gain, speak louder
Accent/dialectTry `medium` or `large-v3` model
Fast speechAsk speakers to slow down

Output Problems

SRT File Doesn't Show Captions in VLC

Fix: Name the .srt file exactly like the video (lecture.mp4 + lecture.srt). Put them in the same folder. In VLC: Subtitle → Sub Track → Track 1.

Captions Out of Sync

Fix: Edit the SRT file's timestamps, or use Subtitle Edit (free) to adjust timing.

Transcript Opens as One Long Line

Fix: Add paragraph breaks manually. Or re-transcribe with --output_format txt.

Try It: Troubleshoot a Practice File

  1. Find any audio file on your computer
  2. Try: python -m faster_whisper transcribe yourfile.mp3 --model tiny
  3. If it works — great! If not, use the fixes above
  4. Document what worked and what didn't

Key Takeaways

  • Most problems have simple fixes — check Python, pip, ffmpeg first
  • Use `tiny` model if you have memory or speed issues
  • Specify language if Whisper guesses wrong
  • Name SRT files to match videos for VLC playback
  • When stuck, check the GitHub issues page for your tool
