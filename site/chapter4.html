Chapter 4

Local Options (Run on Your Computer)

Free AI Transcription and Captions Guide · Asdale Dynamics, LLC

What "Local" Means

The AI runs entirely on your computer. Your audio never leaves your device. No internet needed after setup.

Pros: Total privacy — audio never leaves your computer · No accounts, no API keys, no monthly limits · Works offline · Free forever (open-source models)

Cons: Needs a decent computer · Setup takes 10–30 minutes · Accuracy may be slightly lower than top cloud models · Large model downloads (1–5 GB)

System Requirements

No GPU? No problem. Whisper runs on CPU — it's just 2–5x slower.

The Two Best Local Tools

Option A: Whisper (via faster-whisper) — Recommended

OpenAI's Whisper is the gold standard for free local transcription. faster-whisper is an optimized version that runs 4–8x faster.

Install (Windows, Mac, Linux):

pip install faster-whisper

Transcribe a file:

python -m faster_whisper transcribe meeting.mp3 --model base --output_dir ./output

Model sizes: tiny, base, small, medium, large-v3. Larger = more accurate, slower, bigger download.

Option B: Whisper.cpp — Fastest on CPU

A C++ implementation of Whisper. Very fast, no Python needed. Best for older computers.

Mac (Homebrew): brew install whisper.cpp

Windows / Linux: Download from github.com/ggerganov/whisper.cpp

Option C: Vosk — Lightweight, Offline

Small models (50 MB), runs on anything including Raspberry Pi. Lower accuracy than Whisper, English-focused models are best.

Download from alphacephei.com/vosk/models

Step-by-Step: Transcribe a Lecture Locally

  1. Transfer the file to your computer (USB, email, AirDrop)
  2. Install faster-whisper: pip install faster-whisper
  3. Transcribe: python -m faster_whisper transcribe lecture.mp3 --model base --output_format srt --output_dir ./transcripts
  4. Wait (~5–10 minutes per hour of audio on CPU)
  5. Open the result: transcripts/lecture.srt or transcripts/lecture.txt

Converting Audio Formats

Whisper accepts MP3, WAV, M4A, OGG, FLAC, and most video formats. If needed, convert with ffmpeg:

ffmpeg -i input.m4a -ar 16000 -ac 1 output.wav

Privacy Checklist for Local Tools

  • ✅ No account required
  • ✅ No API key needed
  • ✅ No internet needed after model download
  • ✅ Audio never leaves your computer
  • ✅ Model files stay on your disk

Local = safest option for sensitive audio.

Try It: Transcribe a 1-Minute Clip

  1. Record 1 minute of yourself speaking on your phone
  2. Transfer to computer as test.mp3
  3. Run: pip install faster-whisper
  4. Run: python -m faster_whisper transcribe test.mp3 --model tiny --output_format txt
  5. Open test.txt — your first local transcript

Key Takeaways

  • Local = private — audio never leaves your computer
  • faster-whisper is the best starting point
  • Start with `base` model — good balance of speed and accuracy
  • No GPU needed — CPU works, just slower
  • ffmpeg converts any audio/video to Whisper-friendly format
