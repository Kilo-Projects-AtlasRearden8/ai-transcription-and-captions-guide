Key Terms You'll See

Free AI Transcription and Captions Guide · Asdale Dynamics, LLC

Why This Chapter Exists

Tool documentation throws around jargon. This chapter translates it. Bookmark it and come back when you hit an unfamiliar word.

A–Z Glossary

ASR (Automatic Speech Recognition) — The technical term for "speech-to-text." You'll see this in docs and research papers.

Confidence Score — A number (0–1 or 0–100) saying how sure the model is about each word/segment. Low score = likely error.

Diarization / Speaker Diarization — "Who spoke when." Splits audio by speaker: "Speaker 1: Hello. Speaker 2: Hi there."

Hallucination — The model invents words that weren't spoken — common in silence, music, or heavy noise.

Language Model (LM) — Predicts likely word sequences. Turns "wreck a nice beach" into "recognize speech."

Latency — Time between speech and text appearing. Real-time = under 300ms. Batch = minutes/hours.

WER (Word Error Rate) — Standard accuracy metric: (Substitutions + Insertions + Deletions) / Total Words. Lower = better. Human-level ≈ 5%.

VAD (Voice Activity Detection) — Detecting when speech starts and stops. Silences are cut out before transcription.

Quantization — Compressing model weights (int8, int4) — faster, smaller, slightly less accurate.

GPU / CPU — Graphics card vs. main processor — GPU is much faster for AI.

Sample Rate — How many audio snapshots per second. 16 kHz = standard for speech.

Cheat Sheet: What to Look For in Tool Docs

If you see...It means...
"Supports 16 kHz mono WAV"Convert your audio first
"Beam size 5"Accuracy setting — higher = slower
"int8 quantization"Model is compressed — faster, smaller download
"Streaming API"Real-time, for live captions
"Diarization included"Speaker labels come free
"WER 12% on LibriSpeech"Benchmark accuracy — compare apples to apples

Try It: Decode a Real Doc Page

Go to github.com/openai/whisper and scan the README. You'll now recognize:

  • "multilingual" → language model handles many languages
  • "robust to accents" → acoustic model trained on diverse speech
  • "tiny/base/small/medium/large" → model sizes (parameters)
  • "CPU inference" → runs without GPU

Key Takeaways

  • ASR = Automatic Speech Recognition — the formal name
  • Diarization = speaker labels — essential for meetings
  • WER = accuracy metric — lower is better, human ≈ 5%
  • Quantization = smaller/faster model — trade-off: slight accuracy loss
  • Confidence scores = your quality radar — always check low-confidence segments
