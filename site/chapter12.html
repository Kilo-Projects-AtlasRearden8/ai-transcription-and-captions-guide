Free AI Transcription and Captions Guide · Asdale Dynamics, LLC

Choosing the Right Format

Different formats serve different purposes. This chapter helps you pick.

Format Comparison Table

FormatExtensionTimestampsSpeaker LabelsBest For
TXT.txtNoOptionalReading, printing, notes
MD.mdOptionalOptionalDocuments, websites, GitHub
SRT.srtYesNoVideo captions, YouTube, VLC
VTT.vttYesNoWeb video (HTML5)
DOCX.docxNoOptionalWord documents, sharing
PDF.pdfNoOptionalFixed-layout sharing
JSON.jsonYesYesDevelopers, data processing
CSV.csvYesYesSpreadsheets, analysis

Format Details

TXT — Plain Text

Good morning everyone. Today we'll cover three topics.

First, we'll review the budget.

Pros: Opens everywhere, smallest file, easy to edit · Cons: No timestamps, no formatting · Best for: Reading, study notes, quick reference

MD — Markdown

# Meeting Transcript

## Speakers
- Sarah (Manager)
- Mike (Developer)

## Transcript

[00:00] **Sarah:** Good morning, everyone.

Pros: Readable plain text, formatting (headers, bold, lists), works on GitHub · Best for: Documentation, blogs, version-controlled documents

SRT — SubRip Subtitle

1
00:00:01,000 --> 00:00:04,000
Good morning everyone.

Pros: Universal caption format, works in YouTube/VLC/players · Best for: Video captions, subtitles

JSON — Structured Data

{
  "segments": [
    {
      "start": 0.0,
      "end": 4.0,
      "text": "Good morning everyone.",
      "speaker": "Speaker 1",
      "confidence": 0.95
    }
  ]
}

Pros: Complete data (timestamps, speakers, confidence), machine-readable · Best for: Developers, custom tools, data analysis

Quick Decision Guide

Your GoalRecommended Format
Read on your phoneTXT or MD
Add captions to videoSRT
Put on a websiteVTT
Share with a teamDOCX or PDF
Analyze with codeJSON
Import to spreadsheetCSV
Publish on GitHubMD
Study notesTXT or MD

Converting Between Formats

Multiple formats from Whisper

python -m faster_whisper transcribe audio.mp3 \
  --model base \
  --output_format srt,txt,json \
  --output_dir ./output

This creates audio.srt, audio.txt, and audio.json in one run.

Try It: Export in Three Formats

  1. Take any transcript you've created
  2. Save it as: transcript.txt (plain text)
  3. Save it as: transcript.md (add a title header #)
  4. Save it as: transcript.srt (if you have timestamps)
  5. Open each file and notice the differences
  6. Decide which format you'll use for your project

Key Takeaways

  • TXT = simplest, works everywhere
  • SRT = video captions, universal player support
  • MD = formatted, GitHub-friendly, good for documentation
  • JSON = for developers and data tools
  • Whisper outputs multiple formats at once — use --output_format srt,txt,json
